# CITL Technical Writing Creator v1.0

> **Shared Authorship** — CITL Development Team, Renton Technical College
> **Project Lead:** Doc McDowell

AI-assisted tutorial and technical documentation generator for IT training programs. Uses local Ollama LLMs to draft step-by-step guides, SOPs, and training materials — formatted for immediate curriculum delivery.

## What It Does

- **Tutorial Generator** — AI-drafts step-by-step IT tutorials from a title and skill description
- **Procedure Writer** — generates SOPs for common IT tasks
- **Training Material Creator** — produces structured handouts, lab guides, and reference cards
- **Export to Word/Markdown** — formatted output for LMS upload or print
- **Local LLM powered** — fully offline with Ollama

## Quick Start

```bash
pip install -r requirements.txt
python citl_technical_writing_tutorial_creator.py
```

Requires [Ollama](https://ollama.ai) running locally.
